# Cortex Guard

CYBERCORTEX LITE — MASTER FRONTEND UI PROMPT

ROLE

You are a senior SaaS product designer, UI/UX designer, frontend engineer, accessibility specialist, and design-system architect.

Build the complete frontend UI for a premium cybersecurity SaaS product called CyberCortex Lite.

The product is an AI-powered cybersecurity assistant designed to help everyday users, students, freelancers, startups, small businesses, and developers understand suspicious links, scam messages, password safety, and website security.

This task is FRONTEND ONLY.

Do not build fake security logic, fake scanning systems, fake AI responses, or pretend that a scan actually happened.

Create the complete polished frontend and make it ready to connect to a real backend later.

1. MAIN DESIGN GOAL

The website must look like a real premium cybersecurity startup, not a hackathon template.

The visual quality should feel comparable to a polished modern SaaS product.

The design should communicate:

Trust

Security

Intelligence

Simplicity

Professionalism

Calmness

Modern technology

Avoid making the website look like a stereotypical "hacker website."

Do NOT use:

excessive neon

excessive glowing effects

aggressive red everywhere

black backgrounds with bright green hacker text

excessive gradients

excessive glassmorphism

huge complicated dashboards

excessive animations

clutter

visual noise

The product should feel calm, premium, minimal, intelligent, and trustworthy.

2. VISUAL STYLE

Use a sophisticated dark cybersecurity SaaS theme.

Base background:

deep charcoal / near-black

slightly cool undertone

never pure black everywhere

Primary accent:

sophisticated electric blue

Secondary accent:

subtle violet / indigo

Security success:

muted green

Warning:

warm amber

Danger:

controlled muted red

Do not make colors extremely saturated.

Use contrast carefully.

Use:

low contrast for secondary information

medium contrast for normal content

high contrast for important actions and warnings

The interface should be comfortable to look at for long periods.

Avoid eye strain.

3. DESIGN SYSTEM

Create a consistent design system throughout the entire application.

Use:

consistent spacing

consistent border radius

consistent typography

consistent button styles

consistent card styles

consistent icon sizes

consistent shadows

consistent hover states

consistent status indicators

Cards should feel lightweight and premium.

Use subtle borders and extremely soft shadows.

Avoid heavy borders.

Avoid making every element look like a floating glass panel.

Use glass effects only where they genuinely improve the design.

4. TYPOGRAPHY
